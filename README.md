# 个人记账本 Bookkeeper

> 软工实践现场编程作业 · FitPulse 团队

一个简洁的个人记账 Web 应用，支持收支记录、多维度统计和数据导入导出。

## 快速开始

```bash
pip install -r requirements.txt
python app.py
```

打开 http://localhost:5000
